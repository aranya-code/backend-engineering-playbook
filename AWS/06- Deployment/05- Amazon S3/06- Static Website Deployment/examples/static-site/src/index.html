THE ARCHITECTURE

Simple delivery. Strong boundaries.

CloudFront serves website content from a private S3 bucket. Visitors access the distribution, not the storage origin directly.

◎

Amazon CloudFront

Distributes content through edge locations, terminates HTTPS, and applies caching policies close to visitors.

Content delivery
▣

Private Amazon S3

Stores the static website files with Block Public Access enabled. Objects are retrieved through the authorized CloudFront origin.

Object storage
⌘

Origin Access Control

Signs origin requests using AWS Signature Version 4 and restricts bucket access to the intended CloudFront distribution.

Origin security
!

Security principle: This example does not enable S3 static website hosting or public bucket access. CloudFront uses the S3 REST origin with Origin Access Control.

DESIGNED FOR PRODUCTION

Deployment practices that matter

The example demonstrates the operational controls needed for a maintainable static website delivery workflow.

01

Secure by design

Keep the origin private, enforce HTTPS, and grant only the permissions required by CloudFront.

02

Cache intentionally

Use short-lived caching for HTML and long-lived immutable caching for content-hashed static assets.

03

Deploy consistently

Provision infrastructure with Terraform and use an automated workflow to validate and publish website assets.

04

Validate every release

Run post-deployment smoke tests to check HTTP responses, expected content, and delivery behavior.
